ABOUT Engine7

Engine7 is a C++ 3D engine that uses brushes for the level geometry.
The engine uses: GLFW, GLEW, ImGui, OpenAl(openal-soft) libraries

Brushes can be imported via the OBJ file that Trenchbroom creates.
The best way to store maps for the engine is using .gems files. However, loading using .OBJ with .MAP is possible.

Engine7 has some common engine features such as:

  • scripting with classes
  • lighting system (point,spot lights)
  • collisions
  • key binds
  • 3D audio
  • entity naming

As well as:

  • world raycast
  • particle system
  • PBR
  • Flood Light (with shadows)

Engine7 supports PBR textures. They are .BMP (24bit uncompressed) textures. For every material there are 2 textures:

  • BASE
  • DATA

DATA texture uses Red and Green color channels. Where Red is for metallic parameter and Green is for roughness (shininess)

.GEMS format structure

  1. int BrushN | Brush Number in a level
  2. Brushes | (slightly compressed. Unused sides removed)
  3. unsigned int EntN | Entity count
  4. each entity DEBUG name (64 bytes)
  5. entity custom data. any format. Use Save Load function for that.
