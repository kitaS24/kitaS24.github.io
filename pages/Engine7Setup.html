Engine7 Setup

How to Compile Engine7

The first step is to compile the project. This project uses CMake.
The following commands create a "Build" folder, then build the engine in Release mode.


  mkdir Build
  cd Build
  cmake ..
  cmake --build . --config Release

CMake does not build OpenAl Soft automatically. To compile OpenAl, get OpenAl (openal-soft). Guides can be found in the OpenAl Soft README, or it can be built using:


  mkdir Build
  cd Build
  cmake ..
  cmake --build . --config Release

After compiling, copy OpenAl32.dll into the engine's Build folder.

If you are using the example project, it should launch.

If you are beginning from scratch (you can make your life easier by starting from the tutorial), make sure that you create the following files inside the "Game" folder:

  • EntManager.h
  • EntUser.h
  • GameEnt.cpp
  • GameSubsys.cpp
Next, create "textures" and "shaders" in the Build folder.

Folder "textures" should contain "textures.ini". This file tells the engine which textures are available. Also, folder "textures" should contain your textures (in 24-BIT BMP). The engine supports 2 types of textures: COLOR, DATA

Folder "shaders" must contain your shaders, the engine comes with PBR shaders. (Each shader consists of a Vertex and a Fragment shaders). Shaders are stored as text files, written in GLSL (version 120)
